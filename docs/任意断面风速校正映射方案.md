# 基于 Wei 矩形模型的任意巷道断面风速校正方案

## 1. 文档目的

本文档给出一套从单点风速反演巷道截面平均风速和风量的统一方案。方案以 Wei 2019 矩形巷道模型为基础，把其中仅适用于矩形的等效壁面距离替换为通用几何映射，使模型能够处理：

- 矩形巷道；
- 直墙半圆拱巷道；
- 标准三心拱巷道；
- 等腰梯形巷道。

方案分为两个阶段：

1. **第一代工程模型：径向归一化映射。** 实现简单、计算快速，并能在数学上保证速度分布的截面平均值为 1。
2. **第二代改进模型：真实最短壁距映射。** 更符合壁面湍流的物理意义，用于降低拱肩、圆弧连接处和梯形角部的映射误差。

需要特别说明：截面平均值守恒是数学性质，不等于模型已经获得工程精度验证。半圆拱中央测线可以利用 Zhang 2022 的数据验证；三心拱、梯形的二维精度仍需要现场数据或 CFD 验证。

---

## 2. 问题定义

已知：

- 巷道断面几何参数；
- 测点坐标 \(P=(x,y)\)；
- 测点风速 \(u_m\)；
- 壁面等效粗糙度 \(\varepsilon\)，或 Darcy 摩擦系数 \(f_D\)。

需要计算：

- 截面平均风速 \(\bar u\)；
- 巷道风量 \(Q\)。

统一计算关系为：

\[
\bar u=\frac{u_m}{\Phi(P)}
\]

\[
Q=A\bar u
\]

其中 \(A\) 是断面面积，\(\Phi(P)=u(P)/\bar u\) 是测点速度与平均速度的比值。整个方案的关键，就是根据断面形状、测点位置和壁面摩擦确定 \(\Phi(P)\)。

---

## 3. Wei 原始模型及其推广思路

### 3.1 Wei 矩形模型

Wei 使用的粗糙圆管速度分布为：

\[
\Phi_{\mathrm{Wei}}
=
\frac{u}{\bar u}
=
\frac{\ln(y/\varepsilon)+3.4}
{\ln(r_0/\varepsilon)+1.9}
\]

其中：

- \(y\) 是等效壁面距离；
- \(\varepsilon\) 是等效粗糙度；
- \(r_0\) 是等效圆管半径。

对于宽度为 \(W\)、高度为 \(H\) 的矩形：

\[
r_0=\frac{WH}{W+H}=\frac{2A}{P_w}=\frac{D_h}{2}
\]

Wei 给出的矩形等效壁距为：

\[
y=\frac{WH}{W+H}-\frac{2ab}{a+b}
\]

这里 \(a,b\) 是测点到水平、竖直中心线的距离。这个表达式只适用于矩形，而且当 \(a=0\) 或 \(b=0\) 时会出现不合理退化，因此不能直接推广到拱形和梯形断面。

### 3.2 推广原则

推广时保留 Wei 的速度模型，替换它的几何部分：

\[
\text{矩形特定壁距 }y
\quad\Longrightarrow\quad
\text{任意断面的等效壁距 }\delta(P)
\]

所有断面统一采用水力半径定义：

\[
\boxed{r_0=\frac{2A}{P_w}}
\]

其中 \(P_w\) 是包含底板、墙面和拱顶在内的全部湿周。

---

## 4. 第一代方案：径向归一化映射

### 4.1 映射定义

在断面内部选择映射中心 \(C=(x_c,y_c)\)。对于测点 \(P\)：

\[
\rho=|P-C|
\]

当 \(P\ne C\) 时，射线方向为：

\[
\mathbf e=\frac{P-C}{|P-C|}
\]

从 \(C\) 沿 \(\mathbf e\) 发出射线：

\[
X(t)=C+t\mathbf e,\qquad t\ge 0
\]

射线与巷道边界的第一个有效交点距离记为 \(\rho_b(\theta)\)。定义：

\[
\boxed{\eta=\frac{\rho}{\rho_b(\theta)}}
\]

于是映射中心满足 \(\eta=0\)，断面边界满足 \(\eta=1\)。对应的等效圆管坐标和壁距为：

\[
r_e=r_0\eta
\]

\[
\boxed{
\delta=r_0-r_e
=r_0(1-\eta)
=r_0\left(1-\frac{\rho}{\rho_b}\right)
}
\]

### 4.2 代入 Wei 模型

\[
\boxed{
\Phi_{\mathrm{Wei}}
=
\frac{
\ln\left[
\dfrac{r_0}{\varepsilon}
\left(1-\dfrac{\rho}{\rho_b}\right)
\right]+3.4
}{
\ln(r_0/\varepsilon)+1.9
}
}
\]

然后计算：

\[
\bar u=\frac{u_m}{\Phi_{\mathrm{Wei}}},
\qquad
Q=A\bar u
\]

### 4.3 显式摩擦系数版本

Wei 模型可以改写为：

\[
\Phi_{\mathrm{Wei}}
=1+B_{\mathrm{Wei}}
\left[
\ln\left(\frac{\delta}{r_0}\right)+\frac32
\right]
\]

其中：

\[
B_{\mathrm{Wei}}
=\frac{1}{\ln(r_0/\varepsilon)+1.9}
\]

根据 Darcy 摩擦系数与摩擦速度的关系：

\[
u_\tau=\bar u\sqrt{\frac{f_D}{8}}
\]

可将 Wei 的隐式粗糙度斜率替换为：

\[
B_f=\frac{\sqrt{f_D/8}}{\kappa}
\]

得到：

\[
\boxed{
\Phi_f
=1+
\frac{\sqrt{f_D/8}}{\kappa}
\left[
\ln(1-\eta)+\frac32
\right]
}
\]

其中 \(\kappa\approx0.40\)。如果资料给出的是 Fanning 摩擦系数 \(f_F\)，必须先换算：

\[
f_D=4f_F
\]

### 4.4 截面平均值守恒

对于以 \(C\) 为中心的任意星形断面：

\[
A=\frac12\int_0^{2\pi}\rho_b^2(\theta)\,d\theta
\]

径向归一化后有：

\[
\frac1A\int_A\ln(1-\eta)\,dA=-\frac32
\]

因此：

\[
\boxed{\frac1A\int_A\Phi_f\,dA=1}
\]

这个结论与断面的具体形状无关，是本方案采用径向映射的重要理由。

---

## 5. 映射中心的选择

径向模型能够保持面积平均值，但局部预测结果依赖映射中心。因为 \(\eta=0\) 对应模型中的最高风速区域，所以映射中心应尽量接近实际速度核心。

建议设置三种模式：

1. **几何默认模式：** 使用断面形心；
2. **兼容模式：** 使用总高度中点 \((0,H/2)\)，便于与前面的半圆拱推导保持一致；
3. **标定模式：** 使用中央测线、现场网格测风或 CFD 得到的最大风速位置 \((0,y_{\max})\)。

项目初期可以采用兼容模式或形心模式，但应把 \(y_c\) 设计成可配置参数，不能写死在速度模型中。

## 6. 半圆拱映射

### 6.1 几何参数

这里的半圆拱由直墙和半圆形拱顶组成。设：

- 宽度为 \(B\)；
- 总高度为 \(H\)；
- 拱顶半径为 \(R=B/2\)；
- 直墙高度为 \(h=H-R\)。

采用以断面竖直中心线为 \(x=0\) 的坐标系：

- 底板：\(y=0\)，\(-R\le x\le R\)；
- 左墙：\(x=-R\)，\(0\le y\le h\)；
- 右墙：\(x=R\)，\(0\le y\le h\)；
- 拱顶圆心：\(O=(0,h)\)；
- 拱顶圆弧：\(x^2+(y-h)^2=R^2\)，且 \(y\ge h\)。

面积：

\[
\boxed{A=Bh+\frac{\pi R^2}{2}}
\]

湿周：

\[
\boxed{P_w=B+2h+\pi R}
\]

### 6.2 射线与边界求交

底板候选距离：

\[
t_{\mathrm{floor}}=-\frac{y_c}{e_y}
\]

左右墙候选距离：

\[
t_{\mathrm{right}}=\frac{R-x_c}{e_x},
\qquad
t_{\mathrm{left}}=\frac{-R-x_c}{e_x}
\]

所有线段交点都必须检查是否落在线段有效范围内。

射线与拱顶圆弧求交时，令 \(\mathbf q=C-O\)：

\[
t_\pm
=-\mathbf q\cdot\mathbf e
\pm
\sqrt{
(\mathbf q\cdot\mathbf e)^2-
(|\mathbf q|^2-R^2)
}
\]

只保留 \(t>0\) 且交点满足 \(y\ge h\) 的结果。把所有有效候选距离取最小值：

\[
\rho_b=\min(t_i\mid t_i>0)
\]

### 6.3 映射中心建议

第一版可取：

\[
C=\left(0,\frac H2\right)
\]

如果采用形心，则半圆拱形心高度为：

\[
y_c=
\frac{
Bh\cdot h/2+
(\pi R^2/2)\left(h+4R/(3\pi)\right)
}{A}
\]

最终应利用 Zhang 2022 中央竖线数据比较两种中心选择，并允许标定 \(y_c\)。

## 7. 标准三心拱映射

### 7.1 几何参数

设：

- 巷道宽度为 \(B\)；
- 直墙高度为 \(h\)；
- 拱高为 \(f\)；
- 总高度为 \(H=h+f\)；
- 中央大圆半径为 \(R\)；
- 左右小圆半径为 \(r\)。

中央大圆圆心：

\[
\boxed{O_0=(0,h+f-R)}
\]

右侧小圆圆心：

\[
\boxed{O_R=(B/2-r,h)}
\]

左侧小圆圆心：

\[
\boxed{O_L=(-B/2+r,h)}
\]

标准三心拱应满足大小圆内切条件：

\[
\boxed{
|O_R-O_0|
=
\sqrt{(B/2-r)^2+(R-f)^2}
=R-r
}
\]

项目在接收几何参数时，应检查该等式是否在允许误差范围内成立。

只输入 \(B,H,f\) 一般不能唯一确定 \(R,r\)。工程输入应采用以下两种方式之一：

- 直接输入设计图中的 \(R,r\) 和圆弧角度；
- 选择明确的标准三心拱参数表，由程序根据拱高比读取相应系数。

### 7.2 圆弧切点

令：

\[
d=|O_R-O_0|=R-r
\]

右侧切点：

\[
\boxed{
T_R=O_0+\frac{R}{d}(O_R-O_0)
}
\]

左侧切点由对称性得到：

\[
\boxed{T_L=(-T_{R,x},T_{R,y})}
\]

边界由以下部分组成：

1. 底板；
2. 左、右直墙；
3. 左侧小圆弧；
4. 中央大圆弧；
5. 右侧小圆弧。

### 7.3 射线与三段圆弧求交

对任意圆弧 \((O_i,R_i)\)，统一计算：

\[
\mathbf q_i=C-O_i
\]

\[
t_\pm
=-\mathbf q_i\cdot\mathbf e
\pm
\sqrt{
(\mathbf q_i\cdot\mathbf e)^2-
(|\mathbf q_i|^2-R_i^2)
}
\]

每一个圆弧必须保存：

- 圆心；
- 半径；
- 起始角；
- 终止角；
- 顺时针或逆时针方向。

计算出交点后，用角度范围判断它是否属于当前圆弧。最后将三段圆弧、两段直墙和底板的有效交点距离统一取最小值。

### 7.4 面积和湿周

若单侧小圆弧圆心角为 \(\theta_s\)，中央大圆弧的一半圆心角为 \(\theta_c\)，则：

\[
\boxed{P_w=B+2h+2r\theta_s+2R\theta_c}
\]

面积和形心建议由解析圆弧 Green 积分统一计算：

\[
A=\frac12\oint_{\partial\Omega}(x\,dy-y\,dx)
\]

这样可以避免为不同拱高比维护多套面积经验公式。

## 8. 等腰梯形映射

### 8.1 几何参数

设：

- 下底宽度为 \(B\)；
- 上底宽度为 \(b\)；
- 高度为 \(H\)。

采用中心坐标，四个顶点为：

\[
V_1=(-B/2,0),\qquad V_2=(B/2,0)
\]

\[
V_3=(b/2,H),\qquad V_4=(-b/2,H)
\]

面积：

\[
\boxed{A=\frac{(B+b)H}{2}}
\]

斜边长度：

\[
L_s=\sqrt{H^2+\left(\frac{B-b}{2}\right)^2}
\]

湿周：

\[
\boxed{P_w=B+b+2L_s}
\]

几何形心：

\[
\boxed{
C=\left(0,\frac{H(B+2b)}{3(B+b)}\right)
}
\]

### 8.2 射线与线段求交

对任意边：

\[
X=A_e+u\mathbf s,\qquad 0\le u\le1
\]

射线为：

\[
X=C+t\mathbf e
\]

利用二维叉积：

\[
\boxed{
t=
\frac{\operatorname{cross}(A_e-C,\mathbf s)}
{\operatorname{cross}(\mathbf e,\mathbf s)}
}
\]

\[
\boxed{
u=
\frac{\operatorname{cross}(A_e-C,\mathbf e)}
{\operatorname{cross}(\mathbf e,\mathbf s)}
}
\]

有效条件为：

\[
t>0,\qquad 0\le u\le1
\]

遍历四条边并取最小正 \(t\)，得到 \(\rho_b\)。

---

## 9. 通用几何接口设计

几何与速度模型必须解耦。建议定义如下接口：

```cpp
class CrossSection {
public:
    virtual double area() const = 0;
    virtual double wettedPerimeter() const = 0;
    virtual bool contains(const Point2D& point) const = 0;
    virtual Point2D defaultMappingCenter() const = 0;
    virtual double rayBoundaryDistance(
        const Point2D& center,
        const Vector2D& direction) const = 0;
    virtual double trueWallDistance(const Point2D& point) const = 0;
};
```

断面实现：

```text
RectangleSection
SemiCircularArchSection
ThreeCenteredArchSection
IsoscelesTrapezoidSection
```

统一映射结果：

```cpp
struct MappingResult {
    double rho;
    double rhoBoundary;
    double eta;
    double equivalentRadius;
    double equivalentWallDistance;
};
```

映射伪代码：

```text
r0 = 2 * section.area() / section.wettedPerimeter()
C  = configuredCenter or section.defaultMappingCenter()

if point == C:
    eta = 0
else:
    direction = normalize(point - C)
    rho = distance(point, C)
    rhoBoundary = section.rayBoundaryDistance(C, direction)
    eta = rho / rhoBoundary

delta = r0 * (1 - eta)
```

速度模型单独定义：

```text
WeiRoughnessModel(delta, r0, epsilon)
FrictionFactorLogModel(eta, f_D, kappa)
FrictionFactorLogWakeModel(eta, f_D, kappa, Pi)
```

## 10. 第二代方案：真实最短壁距模型

### 10.1 改进原因

径向映射隐含了一个假设：等风速线可以近似看成巷道边界围绕映射中心同比缩小后的形状。该假设在断面主体区域可能成立，但在以下位置误差可能较大：

- 半圆拱的墙—拱肩连接区域；
- 三心拱大小圆弧连接区域；
- 梯形锐角附近；
- 存在明显二次流的区域。

湍流对数律中的壁面距离，物理上应当是测点到壁面的法向最短距离，而不是径向缩放得到的等效距离。

### 10.2 真实最短壁距

定义：

\[
\boxed{
d_w(P)=\min_{X\in\partial\Omega}|P-X|
}
\]

对于直线段，计算点到线段的最短距离；对于圆弧，先计算点到圆周的径向距离，再判断最近点是否位于圆弧角度范围内，否则取到圆弧端点的距离。

定义几何函数：

\[
G(P)=\ln\left(\frac{d_w(P)}{r_0}\right)
\]

通过截面数值积分计算：

\[
\mu_G=\frac1A\int_A G(P)\,dA
\]

显式摩擦系数模型写成：

\[
\boxed{
\Phi_{\mathrm{wall}}
=1+
\frac{\sqrt{f_D/8}}{\kappa}
[G(P)-\mu_G]
}
\]

它自动满足：

\[
\frac1A\int_A\Phi_{\mathrm{wall}}\,dA=1
\]

相比径向模型，这种方法：

- 不需要用射线定义等效壁距；
- 更符合近壁对数律；
- 不依赖映射中心来计算壁距；
- 更适合梯形角部和三心拱连接处。

但是，核心区仍可能需要额外的尾流或二次流修正。

### 10.3 尾流修正

可在基本模型中加入零均值尾流项：

\[
\boxed{
\Phi
=1+
\frac{\sqrt{f_D/8}}{\kappa}
\left[
G-\overline G+
\Pi(W-\overline W)
\right]
}
\]

其中：

- \(W\) 是核心区形状函数；
- \(\Pi\) 是尾流强度；
- \(\Pi\) 应使用 Zhang 数据、现场测量或 CFD 标定。

## 11. 为什么不优先采用保角映射

把矩形、梯形或拱形通过保角变换映射到圆，在数学上是可行的，但不建议作为当前项目的主路线：

- 湍流动量方程在保角映射下不会自动保持同一速度解；
- 截面平均时必须引入面积 Jacobian；
- 多圆弧和角点会增加数值复杂度；
- 映射更精确不代表速度场更精确；
- 工程误差很可能仍由粗糙度、映射中心和二次流主导。

因此，当前更合理的顺序是：径向映射、真实壁距映射、CFD/现场标定，而不是先实现复杂的保角映射。

---

## 12. 模型适用条件和限制

模型适用于：

- 稳定、充分发展的湍流；
- 测点所在断面远离风机、弯头、风门、车辆和明显障碍物；
- 断面形状近似凸形或相对于映射中心为星形；
- 测点没有紧贴壁面。

模型不应直接用于：

- 明显回流和分离区；
- 距离弯道或局部构筑物很近的断面；
- 边界几何严重破损、无法用设计断面表示的巷道；
- 位于壁面粗糙元内部或对数层以下的测点。

当 \(\delta\to0\) 或 \(d_w\to0\) 时，对数函数会发散。工程实现不能简单截断后继续使用原归一化常数，因为这会破坏平均值守恒。正确方法是采用近壁复合壁面律，或对正则化后的整个速度函数重新进行截面归一化。

## 13. 验证方案

### 13.1 几何单元测试

每一种断面必须验证：

- 面积和湿周与解析结果一致；
- 映射中心位于断面内部；
- 任意有效测点满足 \(0\le\eta<1\)；
- 边界点满足 \(\eta\approx1\)；
- 左右对称点得到相同的映射结果；
- 三心拱圆弧连接点处映射连续；
- 梯形顶点附近不会选中错误边界；
- 半圆拱退化条件下与已有半圆模型一致。

### 13.2 数值守恒测试

在断面内进行规则网格积分或 Monte Carlo 积分，验证：

\[
\left|
\frac1A\int_A\Phi\,dA-1
\right|<\epsilon_{\mathrm{num}}
\]

建议第一版数值容差设置为 \(10^{-3}\)，解析或高精度积分测试设置为 \(10^{-6}\)。

### 13.3 数据验证

建议按以下顺序进行：

1. 使用 Wei 2019 数据复现原始矩形模型；
2. 在相同测点上比较 Wei 原壁距和径向壁距；
3. 使用 Zhang 2022 半圆拱中央测线数据验证半圆映射；
4. 对半圆拱进行二维 CFD，检查拱肩和直墙附近误差；
5. 对三心拱和梯形建立相同 \(Re\)、相对粗糙度条件下的 CFD 数据；
6. 比较径向模型与真实最短壁距模型；
7. 最后使用独立现场数据验证，不能只使用参与参数标定的数据报告误差。

建议至少报告：

- 平均绝对相对误差；
- 最大相对误差；
- 95% 分位误差；
- 不同测点区域的误差分布；
- 反演风量误差；
- 对映射中心、粗糙度和摩擦系数的敏感性。

## 15. 最终建议

项目应保留三层模型：

1. **Wei 原始矩形模型：** 用于论文复现和基线比较；
2. **径向等效圆模型：** 作为半圆拱、三心拱和梯形的第一版统一工程模型；
3. **真实最短壁距模型：** 作为后续高精度模型。

第一版核心公式为：

\[
\boxed{
\delta(P)
=r_0\left(1-\frac{|P-C|}{\rho_b(\theta)}\right)
}
\]

配合 Wei 粗糙度公式，或推荐的显式摩擦系数公式：

\[
\boxed{
\bar u
=
\frac{u_m}{
1+
\dfrac{\sqrt{f_D/8}}{\kappa}
\left[
\ln\left(1-\dfrac{|P-C|}{\rho_b(\theta)}\right)
+\dfrac32
\right]
}
}
\]

这条技术路线能够最大限度复用 Wei 的理论结构，同时把断面几何、速度分布和摩擦参数解耦，为后续加入新断面、尾流修正和 CFD 标定保留清晰接口。
