# V2 前端使用说明

前端沿用 Streamlit，只改 Project_1_v2，不改 Project_1 和 C++ 模型。UI调用明确的模型ID，不使用AUTO猜测算法。

## 启动

1. 在V2文件夹运行 run_grpc_server.cmd，保持窗口运行。
2. 运行 run_frontend.cmd。默认浏览器地址 http://127.0.0.1:8051，gRPC为127.0.0.1:51051。
3. 如果原版占用端口，分别运行：

```powershell
.\.venv\Scripts\python.exe run_backend.py --port 51052
.\.venv\Scripts\python.exe run_frontend.py --port 8052 --grpc-address 127.0.0.1:51052
```

前后端命令分别在两个终端执行；前端不会自动启动或停止已有后端。不要让V2前端连接到不支持径向模型的原版服务。前端会校验返回的模型ID。

## 计算界面

- 多断面V2：矩形、直墙半圆拱、标准相切三心拱、等腰梯形的内部点。
- 页面统一使用径向映射，不再提供工作区切换、原始 Wei 矩形算法选项或模型对照。

## 输入

宽高和坐标单位m；风速m/s；粗糙度界面以mm输入，发送RPC前除1000。5.5mm对应0.0055m。它不是矿井α或Darcy摩擦系数。

坐标原点为底板左端，x向右、y向上。梯形上底居中，允许上底更宽，此时上部可出现负x。半圆拱H指总高，H≥W/2。三心拱输入W、直墙h、大圆R、小圆r，自动推导f=R-sqrt((R-r)^2-(W/2-r)^2)，检查相切条件。默认中心为(W/2,H/2)，径向模式可显式自定义中心。

示例按钮只填值，不自动计算。圆拱和Wei点111是文献输入；三心拱是几何示例，梯形只采用文献几何、速度为演示值。没有将示例误标为全部实测。

几何示意图按相同横纵比例绘制，宽度限制为460像素，不再铺满页面；展示C中心、P传感器和射线边界交点B，不是速度云图。速度和校正系数只取自后端。

## 输出和状态

结果区只显示K、估算均速、m³/s和m³/min风量、面积。不再展示映射中间参数、模型信息折叠区、重复适用性警告、验证资料区或JSON下载按钮。后端输出和会话内的完整计算记录不变；侧栏仅保留后端连接设置和启动说明。

修改输入或服务地址后隐藏旧结果，需重新计算；请求失败不会继续展示上次成功值。

仅允许内部有效测点；更细的对数模型适用域、粗糙度上限由后端再次校验。计算成功不代表工程合格，近壁、障碍物、分汇流有明显风险。不生成后端不支持的二维风场。

## 测试

```powershell
.\.venv\Scripts\python.exe tests/test_frontend_v2.py
.\.venv\Scripts\python.exe tests/test_radial_rpc.py --exe build-codex/airflow_cli.exe
```

前端测试使用Streamlit AppTest及动态本地端口的真实gRPC/C++服务，结束时释放服务。覆盖四形状、三心拱非法参数、内部点校验、mm转换、中心选项、输入变更状态及网络错误，以及旧版入口、算法选项和指定提示已移除。
