# 巷道风速校正项目介绍：算例验证及局限

整理日期：2026年9月21日  
验证对象：当前V2径向映射模型  
用途：项目介绍末章的内容底稿，包含可直接讲述的正文、完整分组结果及资料索引。

> 本文汇总2026年9月9日至20日已有测试记录。本次工作为结果归集与核对，没有重新运行流场仿真、修改模型或按测试结果调参。实验和现场数据来自文献，DNS来自作者公开数据库；不能表述为本项目自行开展了这些现场实验。

## 一、适合放入项目介绍的正文

### 1. 验证思路：既看校正效果，也看适用条件

为了检验由单点风速估计断面平均风速的可行性，项目使用了三类参考数据：矿井现场测量、实体试验，以及CFD和直接数值模拟（DNS）数据。验证覆盖矩形、半圆拱、三心拱和梯形近似断面，但不同断面的证据完整程度不同。

对于同时提供测点位置、点风速和参考均速的算例，将校正结果与参考均速比较，并保留“不进行校正、直接把点风速作为均速”的结果作为基线。对于只有均速线位置或相对速度剖面的资料，则分别检验位置和剖面，不把这些结果当作完整的均速反演验证。

### 2. 主要结果：部分算例有明显改善，规则方管均速线附近吻合较好

**现场算例中，模型在部分测点上体现了校正价值。** Wei矩形断面24个测点的平均绝对相对误差由13.49%降至7.53%，其中21个测点得到改善；但最大误差仍为21.48%，说明改善并不均匀。张浪半圆拱无人员工况中，点风速为3.75 m/s，人工参考风速为3.45 m/s，校正后估计为3.489 m/s，偏差由8.70%降至1.12%。该算例沿用论文共享人工参考值，其证据强度仍受参考测量条件限制。

**规则方管DNS提供了工况更明确的数值检验。** 已测试两个作者数据库中的11个工况。三个高雷诺数工况中，模型预测均速线上的平均绝对速度偏差为0.79%—1.11%，最大偏差为2.37%—4.10%。这支持模型对规则方管均速位置的近似描述。由于这些位置的校正系数本来就是1，该结果验证的是均速线选择的合理性，不代表校正前后误差降低，也不等于全断面精度达到1%。

此外，LDA实体试验拟合剖面的40个评价点，在默认参数条件下，均速估计误差由14.22%降至5.26%。这些评价点来自5个工况的拟合曲线，且默认粗糙度与光滑缩尺模型没有完成物理匹配，因此属于条件性支持证据。

### 3. 局限：结果依赖位置、流场和参数

现有结果也显示，校正并非对所有测点都有收益。测点原本接近断面均速位置时，额外校正可能增加误差；近壁、角部和方向差异明显的区域，统一径向速度关系的偏差更突出。Zhou的入口、分汇流及漏风等复杂现场条件，与当前模型假设不相符，作为适用范围之外的压力测试单独保留。

不同断面也不能直接继承方管的精度：三心拱目前主要验证了部分均速线位置，梯形主要验证了中心速度归一化后的相对剖面，两者都缺少充分的独立点速—均速验证。

**因此，现阶段可将本方法定位为有算例支持的工程近似：在条件合适、参数明确并经过现场校核的情况下，帮助提高单点均速和风量估计的可靠性；其全断面精度和复杂工况适用性仍需继续验证。**

## 三、统计口径与数据去重

### 3.1 各类误差分别代表什么

- **均速反演误差**：E = 100 × (U估/U参考 − 1)。MAPE为各评价点|E|的算术平均。
- **系数检验**：Zhou提供K参考，采用E = 100 × (K模型/K参考 − 1)。输入1仅用于归一化，不是虚构实测速率。
- **位置误差**：E位置 = 100 × (预测距壁距离/参考距壁距离 − 1)。它不能称为风速误差。
- **相对剖面误差**：以实测中心速度锚定，比较其他位置的预测点速与读图实测点速。它不能独立验证断面均速。
- **DNS轮廓误差**：在模型指定轮廓上比较K·uDNS与DNS参考均速。对模型均速线，K=1。
- **DNS区域MAPE**：等面积采样点上单点反演误差绝对值的平均；不是把全断面预测风量与一个参考风量比较所得的单一误差。

文中≤5%、≤10%均为描述性误差区间，没有据此认定工程验收通过。MAPE不是错误概率，不能用“100%−MAPE”表示准确率。

## 七、11个规则方管DNS工况

### 7.1 工况与方法

两个作者数据库均为规则、等截面、充分发展、光滑壁面方管。KIT使用6个工况，Rome使用5个工况文件。KIT的Re_b按半宽与体积平均速度定义；Rome表中Reτ为文件工况标签，两种雷诺数不能直接横向等同。

参考场采用作者统计速度及独立体积均速归一化，并做对称平均和插值。每组均速轮廓取41个评价位置；区域评价使用400×400等面积中点。它们是同一统计场上的相关采样，不是新增实验。

### 7.4 同η方向差异：几何近似的结构限制

模型对相同η赋予相同K，但DNS点速仍随方向变化。若同η方向样本中的最小、最大速度比为a、b，则任何共同K的最大绝对相对反演误差至少为(b−a)/(b+a)。

|工况，η=0.9|共同K可达到的最大误差下界/%|
|---|---:|
|KIT Re_b≈2205 / 2400 / 2600|23.94 / 20.39 / 16.67|
|KIT Re_b≈2900 / 3200 / 3500|14.28 / 11.24 / 8.77|
|Rome Reτ=150 / 220|23.92 / 9.16|
|Rome Reτ=500 / 1000 / 2000|3.35 / 4.90 / 4.60|

这是方向采样的数学下界，不是全断面MAPE。低Re近壁层同时挑战对数速度假设，不能将全部偏差只归因于几何。Wei现场的同η四点也有11.330%的共同K下界，说明仅更换统一一维速度公式未必能解决全部残差。

## 九、需要在项目介绍中交代的局限

### 9.1 位置和方向

中心、边界及沿射线的相对位置可以统一描述，但相同η并不必然具有相同真实风速。近壁、角部以及非圆断面的方向性需要更充分表达。当前结果支持工程近似，尚不支持准确重建全断面风场。

### 9.2 流动状态和壁面条件

现有统一速度关系没有充分适配雷诺数、光滑/粗糙壁和近壁层。低Re与高Re表现不同，默认粗糙度跨尺寸直接使用也会改变结果。参数应由独立依据确定，再用留出数据检验。

### 9.3 模型未表达的现场扰动

入口发展、障碍物、支架、人员、弯道、分汇流及漏风不能只靠空断面几何和一个粗糙度参数完整描述。Zhou及人员扰动数据用于说明这类边界；不是理想直巷条件下的同等验证样本。

### 9.4 不同断面的证据强度不同

矩形有现场多点和方管DNS，但方管不能覆盖所有长宽比。半圆拱有少量现场及位置数据；三心拱主要为缩尺关联式；梯形缺独立截面均速。不能把某一形状的误差范围直接用于其他形状。

### 9.5 参考数据与推广

文献表格舍入、图像数字化、共享均速参考、拟合曲线采样和对称平均均会影响证据解释。尚缺按不同矿井和断面独立留出的现场验证，也未完成传感器误差、安装误差和面积误差的完整传播评价。

当断面面积确定且参考面积相同时，均速估计相对误差会等比例传递到风量。现有速度验证可支持风量估计环节的讨论，但不能据此声称已验证通风网络解算精度、风量调节成效或节能收益。
